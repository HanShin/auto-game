# 랑그릿사 영상 공략의 칸 좌표 실행 규칙

각 미션에 들어가기 전, 실제 게임의 미션 이름·목표·맵·시작 배치를 출처 영상과 대조한다. **영상의 승리 화면까지 먼저 전사한다.** 한 시점의 정지 화면만으로 행동을 확정하지 않고, 각 클릭의 전후 화면에서 선택·미리보기·확정·전투 결과를 구분한다. 전투 중에는 전사된 실행표를 따르며, 불일치가 생긴 구간만 영상으로 돌아가 재검증한다.

## 출격 전 확인표

- [ ] 게임 상세 화면의 미션명·승리 조건·현재 업적/보물 수를 기록했다. 영상은 같은 목표·맵·시작 배치다. 동명 다른 미션이 아니다.
- [ ] 승리까지 **모든 턴 번호와 각 턴 종료**를 대조했다. 이동만 하고 대기하는 턴, 마지막 표식/출구로 가는 턴도 한 행으로 적었다.
- [ ] 각 행동의 영상 최종 흰 경로와 **확정 뒤 칸**을 확인했다. 취소한 후보 칸과 단순 미리보기는 실행 행으로 쓰지 않았다.
- [ ] 기술의 한국어 이름/아이콘, 시전자·대상 상대 칸, 대상 이름/병종, 필요한 경우 첫째·둘째 좌표와 확인 횟수, 공격 뒤 재이동·재행동을 적었다.
- [ ] 턴 마지막 배치와 다음 턴 첫 화면이 이어진다. 출처가 보장하는 업적·보물 범위와 `미확인` 항목을 분리했다.

짧은 행 예: `T10 폭탄맨 S1E1 → 폭탄 E1 → 재이동 N1W1 → 대기 → T11 시작 칸 확인`. 영상의 특정 초와 실전에서 확인할 다음 상태를 함께 적는다. 위 항목이 불명확하면 해당 부분의 공략을 더 확인하고 임의 좌표를 채우지 않는다.

기존에 완주까지 전사하고 검증한 실행표가 있으면 출격 전 그 표의 미션 일치와 남은 목표만 재확인한다. 재출격 때마다 영상을 처음부터 다시 보지 않고, 실제 결과가 어긋난 구간과 수정된 행만 다시 검증한다.

## 실행표 한 행의 필수 정보

| 항목 | 기록 방식 |
| --- | --- |
| 순서 | 턴 번호와 턴 안의 행동 순서. 재행동은 별도 행. |
| 아군 | 행동 시작 전 병종·식별 위치. |
| 입력 단계 | `선택 → 이동 미리보기 → 행동 메뉴 → 기술/공격 대상 선택 → 확인 → 결과` 중 현재 단계. 대상 두 개·재행동·공격 후 이동은 각각 별도 행. |
| 이동 | 시작 아군 칸 기준 `(dx,dy)`와 영상의 **흰 이동 경로**를 시작→경유→도착 순서의 칸 목록으로 적는다. 오른쪽·아래가 양수. 이동 없으면 `(0,0)`. 흰 선이 가려져 경유 칸을 셀 수 없으면 `미확인`. |
| 기술 | `일반 공격`, 게임에서 보이는 기술 이름/색, `대기`, 또는 `상호작용`. |
| 표적 | 기술을 쓰는 아군의 **사용 직전 칸** 기준 대상 `(dx,dy)`, 대상의 이름·진영·병종·주변 유닛과의 위치 관계. 단순히 가장 가까운 유닛을 대상으로 추정하지 않는다. |
| 클릭 전 조건 | 현재 턴·행동 가능한 아군·실제 이동 범위·목표칸 점유자·기술 사용 가능 여부. |
| 클릭 후 조건 | 캐릭터 위치, 행동 메뉴/선택 단계, 공격 미리보기의 **대상 이름과 호위 대상**, 기술 효과, 재행동 여부. 턴 종료 뒤 아군·적의 칸과 상태. |
| 출처 | 영상 URL과 확인한 구간. 미확인은 `미확인`으로 둔다. |

## 수동 실행

1. 영상과 실제 전장 모두에서 선박 모서리·고정 지형·열쇠 위치 같은 **고정 칸**으로 같은 지도 격자 번호를 정한다. 현재 화면에서는 행동할 아군과 다른 확인 가능한 칸 중심을 최소 두 개 기록하고 화면 격자 간격·원점을 다시 계산한다. 이전 화면의 픽셀 좌표는 재사용하지 않는다. 계산만 하는 [수동 참조 모듈](../scripts/langrisser-grid-reference.mjs)을 쓸 수 있다. 이 모듈은 게임을 클릭하지 않는다.
2. 행동할 아군을 반드시 이번 화면의 관측 기준점으로 포함한다. 그 아군의 **현재 칸**에서 상대 좌표를 투영한다. 이동으로 아군 위치가 바뀌거나 화면이 움직이면 새 화면에서 아군을 다시 찾아 기준점을 갱신한다. 계산된 칸이 화면 밖·상단 UI 아래이거나, 기준점의 격자 오차가 크면 입력을 중단한다.
   대화 종료·출격·캐릭터 선택 직후에는 자동 카메라 이동 중인 화면일 수 있다. 지형과 캐릭터 기준점이 안정된 새 화면에서만 누른다. 미리보기에서 의도하지 않은 대상이 선택되면 확정하지 않고 취소하며, 이 취소를 전투 기술 사용으로 기록하지 않는다.
3. 영상에서 이동 클릭 직전과 직후를 모두 보고 **흰 경로선이 지나간 칸과 끝 칸**을 센다. 흰 선은 목표칸의 근거이며, 게임에서 그 칸을 누를 때 동일한 방향·도착 칸의 이동 미리보기가 떠야 한다. 경로가 장애물 때문에 달라도 도착 칸과 행동 결과가 일치하는지 확인하고, 도착 칸 자체가 다르거나 선택이 안 되면 다른 근처 칸을 임의로 누르지 않는다. 미리보기의 캐릭터 모습은 이동 확정으로 취급하지 않는다. 확정 후 다시 위치를 관측한다.
4. 기술은 사용 아군과 기술 아이콘·이름을 먼저 확인한다. **기술을 사용하는 칸을 새 원점**으로 잡고, 영상 속 대상의 정체와 상대 칸을 기록한다. 현재 맵에서는 그 대상 유닛의 발 아래/HP 표시가 속한 칸 중심을 다시 찾아 누른다. 가까이에 여러 유닛이 있으면 이름·진영·병종·주변 배치까지 대조하고, 기술 선택 화면의 표적 표시나 미리보기에서 실제 선택된 대상이 맞는지 확인한다. 대상이 빈칸인 범위 기술은 유닛이 아니라 중심 칸을 기록한다.
5. 공격 확정 전 미리보기의 대상 이름, 양쪽 병종·지형·DEF를 실행표와 대조한다. 맞으면 확정하고 처치·변신·재행동을 확인한 뒤 다음 행으로 간다. 이동·대기만 하는 행은 지정 칸과 턴 전환을 확인한다.
6. 칸이 보이지 않거나, 선택 불가이거나, 대상 이름·병종·지형·결과가 다르면 해당 입력을 보류한다. 출처 영상/사이트와 현재 화면을 다시 확인해 실행표를 수정하고, 필요하면 재시작하여 직접 재검증한다. HP·피해량만 다르고 다음 행동의 위치·대상·생존 조건이 충족되면 차이를 기록하고 계속한다. 불일치 자체를 이유로 사용자에게 질문하거나 응답을 기다리지 않는다.
   한 칸 차이를 다음 행동에서 **출처와 같은 필수 배치로 복구할 수 있으면**, 근거와 조정한 칸을 기록한 뒤 이어간다. 복구 전에는 기술이나 공격을 확정하지 않는다. 단순 HP 차이와 적이 살아남아 다음 행동이 달라진 경우를 구분한다.
7. **전투 패배 시 같은 미션을 재시도한다.** 클리어했으나 업적·상자를 놓치면 지도 카운터와 공략 링크를 미달 기록에 남기고 다음 미션으로 진행한다. 크리스탈은 소비하지 않는다.
8. 승리 뒤에는 같은 스테이지 상세 화면을 열어 미션명·CLEAR/PERFECT·업적·보물 카운터를 확인하고 최신 검증 기록에 남긴다. 완료한 공략 영상은 닫고 다음 미션의 화면을 새로 확인한다. 진행 중에는 현재 미션의 출처 탭 한 개를 기본으로 유지한다.

## 영상 재현 실패를 막는 확인 단계

실행표의 한 행은 캐릭터가 화면에서 움직여 보였다는 이유만으로 완료 처리하지 않는다. **이동 미리보기**에서는 경로선과 파란 도착 표시가 남아 있다. 기술·공격 메뉴가 뜨거나 행동이 확정된 후 실제 칸을 다시 관측해야 한다. 지도 장식(예: `수호의 열쇠`)을 누르면 설명이 열릴 수 있으므로, 선택 가능한 칸 표시와 실제 캐릭터 이동을 확인하지 못한 클릭은 이동으로 기록하지 않는다.

두 지점을 지정하는 기술은 실제 확인창에 맞춰 입력 단계를 기록한다. `밤의 수호자`의 두 열쇠 배치는 `첫 좌표 선택 → 두 번째 좌표 선택 → 확인 한 번`이다. 기술마다 확인 횟수를 임의로 통일하지 않는다. 공격 전에 뜨는 미리보기에서 공략의 적 이름과 실제 방어자·호위자를 모두 비교한다. 예상과 다르면 취소한다. 공격 뒤에는 재행동이 생겼는지, 추가 이동이 필요한지, 다음 행동 시작 칸이 어디인지 다시 기록한다.

턴이 끝나면 아군·핵심 적·열쇠의 **칸 배치표**를 영상의 같은 시점과 대조한다. 화면상 위치뿐 아니라 고정 지도 칸 번호도 함께 비교한다. 첫 불일치가 난 직전의 입력 단계로 돌아가 원인을 찾는다. 피해량이나 치명타 차이만으로 원인을 단정하지 않는다. 맵 배치, 선택 기술, 대상 칸, 전투 미리보기, 사용한 장비·스탯을 순서대로 확인한다. 공략과 다른 적이 목표칸을 점유하거나 기술 범위가 다르면 임의로 다음 행을 진행하지 않는다.

검증된 예시는 [환령의 귀로 무변신 칸 좌표 실행표](langrisser-playbooks/phantom-return-no-lobster-grid-2026-09-28.md)다. 새 미션은 이런 수준의 실행표를 확보한 후 출격한다. 영상에 정확한 칸·기술·대상이 보이지 않는 미션은 추측으로 실행표를 채우지 않는다.
