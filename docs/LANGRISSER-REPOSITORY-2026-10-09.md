# 소스 인계 검증 — 2026-10-09

- 대상 저장소: https://github.com/HanShin/auto-game (기존 커밋 없는 저장소로 확인).
- 포함: 랑그릿사 공략 문서179개, 출처 자료, PC/Mac 수동 진행 기록, 최신 완료 증거 JPG, 좌표 계산 모듈 및 관련 소스·테스트. 사용자가 추가로 명시한 **스타레일/iPad 도구·진행 기록·빈 기기 설정 예시·Appium 의존성**도 함께 포함한다. 과거 랑그릿사 원본 PNG25개는 용량이 커 로컬 보관하고 공유 대상에서 제외했다. 현재 미션 클리어는 CUA 수동 입력으로 수행했으며 별도 전투 자동 실행기를 사용하지 않았다.
- 새 PC 안내: `docs/LANGRISSER-OTHER-PC.md`, 마지막 검증 상태: `data/langrisser/current-session.json`. 폭풍의 우연3턴·업적2/2·보물1/1·첫 보상 수령 완료 후 사용자의 요청대로 중지.
- 제외: 실제 기기 설정 `device.local.json`, 런타임/캐시, 설치 의존성, 빌드 앱, PC 전용 바로가기, 환경·인증 설정. 버전 관리 대상에서 제외한 파일이 추적되지 않는지 확인했다.
- 이전 Mac 절대 경로를 저장소 상대 경로로 정리. 과거 Mac 자동 실행 문서와 현재 Windows 수동 진행 안내를 구분했다.
- `node scripts/portable-check.mjs`를 프로젝트 밖 `C:/`에서 실행해 상대 경로·최신 증거 파일·공략 파일 존재 검사 통과.
- 최초 전체 프로젝트 테스트52개 통과. 공유 범위 축소 후 **랑그릿사 테스트46개 최종 통과**. 최초 샌드박스 실행은 임시 파일 rename 권한 제한으로 실패했으며, 프로젝트 내부 임시 폴더와 허용된 테스트 실행으로 재검증했다. 이후 경로 수정에 맞춰 메뉴 기록의 해시를 갱신했다. 짧은 시간 제한을 가진 기존 테스트 한 건은 병렬 실행에서 실패해 순차 실행으로 최종 확인했다. 테스트는 게임 입력 없이 모의 연결을 사용한다.
- 다른 PC의 실제 게임 설치·로그인·Computer Use 연결은 해당 PC에서 별도 검증해야 한다. 저장소 복제가 게임 연결 자체를 설정하지 않는다.

## 공개 업로드 전 전체 파일 점검

- 최초 전체 업로드 명령은 자동 승인 검토에서 거부됐다. 이유는 공개 저장소에 올릴 전체 파일의 민감정보·개인 경로 검증이 부족하다는 것이며, 거부된 명령은 실행되지 않았다.
- Git에 추가된 전체 파일을 대상으로 자격 증명 토큰·비공개 키와 개인 홈 경로를 검색했다. 토큰·키·개인 홈 경로 일치 없음. 일반적인 password/token/UDID/teamId 단어가 있는 파일은 빈 예시 설정, 설명, 읽기 전용 프로세스 토큰 진단, URL 인증 거부 코드 및 테스트로 확인했다.
- 원래 후보 이미지 **26개 전부**를 직접 시각 검토했다. 게임 전투·미션 상세·업적·보물 화면이며 로그인·계정 설정·개인 메시지·기타 앱 화면은 없다. 최종 공개 이미지는 최신 완료 JPG1개이며 게임 내 보유 재화와 미션 진행 상태를 포함한다.
- 제외 규칙이 실제 기기 설정·환경 파일·런타임·설치 의존성·앱 빌드·로컬 바로가기를 차단하며 추적된 제외 파일은0개임을 확인했다. 전체 파일별 Git blob 해시는 [공개 파일 목록](PUBLICATION-MANIFEST.md)에 고정했다.
- 전체 검증 후 동일 Git push 재검토는 허용됐으나 로컬 Git 자격 증명 부재로 전송이 실패했다. 인증 정보를 소스로 옮기지 않고 연결된 GitHub 앱으로 공개 소스와 최신 증거를 전송한다. 전체 후보를 보존한 로컬 최초 커밋은 별도 로컬 보관 브랜치에 남긴다.
- GitHub 앱의 최초 README 생성도 스타레일/iPad 별도 작업 내용이 포함되어 승인 범위 초과로 거부됐다. 해당 README 섹션·도구·기기 예시 설정·테스트·문서·Appium 의존성을 공개 후보에서 제거하고, 사용자가 요청한 랑그릿사 관련 자료로만 범위를 좁혔다. 두 거부 명령은 외부 변경을 만들지 않았다.
- 이후 사용자가 “스타레일이랑 ipad도 포함해줘”라고 명시하여, 해당 소스와 기록의 공개 범위가 승인됐다. 실제 `device.local.json`·인증 정보·캐시는 계속 제외한다.
