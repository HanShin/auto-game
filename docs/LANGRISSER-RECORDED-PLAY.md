# 출처 기록으로 진행하기

사용자는 스테이지 공략을 먼저 확인·문서화하고, Codex가 그 기록을 참고해 현재 맥에서 실행 중인 랑그릿사를 직접 조작하는 흐름을 요청했다. 전투는 별도 프로그램이나 CLI 실행기가 대신 진행하지 않는다.

## 진행 원칙

- 스테이지 이름·승리 조건·맵을 영상 및 사이트와 대조해 정확히 같은 미션인지 확인한다. 이름만 같은 다른 미션의 행동을 섞지 않는다.
- 턴, 영웅, 기술, 도착 칸, 예상 결과와 출처 시점을 가능한 한 기록한다. 원본에서 읽히지 않는 값은 미확인으로 둔다.
- 실행 전 현재 화면과 첫 행동을 맞춘다. 행동마다 게임 화면을 확인하며 정해진 출처 기록과 비교한다.
- 기록과 화면이 일치하지 않거나 다음 행동이 불분명하면 입력을 멈추고, 관련 공략 사이트를 열어 사용자에게 현재 상황과 모르는 점을 묻는다.
- 승리·모든 업적·모든 보물은 결과 화면의 각 카운터를 확인해서 따로 검증한다.

## 현재 준비 상태

- [공략 목록](LANGRISSER-GUIDES.md)과 [한국어 영상 확인 기록](LANGRISSER-KOREAN-VIDEO-AUDIT.md)은 이전 조사 결과다. 155개 동영상 링크를 전부 시청·전사했다는 뜻은 아니다.
- 본편 1-4에는 중국어 영상에서 확인한 행동 기록이 있지만, 앞선 실제 진행은 9턴에서 영상과 달라져 중단됐다.
- 본편 1-5 「예측할 수 없는 여행」은 2026-09-27 실제 맥 게임에서 **클리어·업적 2/2·보물 1/1(PERFECT)** 완료. [검증된 4턴 번호표](langrisser-playbooks/main-1-5-coordinate-ledger.md)에 캐릭터, 고정 좌표, 기술, 영상 시점, 실패 교정과 결과를 기록했다.
- T3 화면 밖 프레시아를 선택할 때 사용자가 지도만 북쪽으로 옮겨 주었다. 일반 지도 드래그의 도구 입력 문제는 미해결이며 무도움 조작을 보장하지 않는다.

`docs/langrisser-playbooks/`는 조사와 관찰을 사람이 읽을 수 있게 모은다. `data/langrisser/verification/`에는 실제 플레이 중 확인한 화면·결과를 남긴다. 어떤 로컬 JSON/프로그램에 기록이 있다는 이유만으로 실제 게임이 진행되었다고 간주하지 않는다.
