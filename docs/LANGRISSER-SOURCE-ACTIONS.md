# 공략에 근거한 행동 기록

현재 본편 1-4 ‘섬의 손님’은 **9턴에서 입력 중단** 상태다. 이번 재도전에서 상자 발견을 확인했지만, 마지막 공격의 치명타 결과가 영상과 달라 적이 3283 HP로 생존했다. 또한 1턴 프레시아 기술의 추가 입력 실수가 있어 정확 재현에도 실패했다.

[이번 판 전체 검증 기록](LANGRISSER-VALIDATION-2026-09-27.md)에 턴별 실제 행동, 차이, 화면 증거와 프로그램 검증 범위를 저장했다. 독립 프로그램 전투 자동 완주 수는 0개다.

- [일본 위키 본편 1-4](https://langrisser.wikiru.jp/?ゲートの彼方/本編1-4): 증원·보물 위치 보조 자료. 요약만으로 임의 전투 행동을 생성하지 않음.

## 실행 조건

현재는 [저장된 기록 실행 방식](LANGRISSER-RECORDED-PLAY.md)을 사용한다. 정상 실행 중 공략을 다시 열지 않고 준비한 행동·예상 결과·분기를 따른다. 전역 입력 보류 대신 문서화한 version 2 계획만 허용한다. 현재 9턴 복구 경로는 미완성이므로 컴파일되지 않는다.

전투 입력에는 출처에서 확인한 동작 ID와 영상 시점 또는 글 문단이 필요하다. 전체 순서·한국 게임 화면 매핑·정확한 계획 해시도 일치해야 한다. 일시적인 결과 불일치는 로컬 관찰을 반복하고 기록된 대응 분기로 처리한다. 대응이 없거나 계속 모호하면 화면과 이유를 저장해 사용자에게 한 번 요청한다.

현재 필요한 것은 9턴 비치명타 후속 행동의 근거, 체력 OCR 오류 대응, 1턴 실수를 제외한 재검증이다. 2026-09-27 관련 테스트 25개가 통과했으며 이 결과는 실제 전투 완주를 뜻하지 않는다. 네이티브 앱은 재빌드하지 않았다.
