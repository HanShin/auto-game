# 스타레일 화폐전쟁 진행 기록 — 2026-10-03

- 사용자 요청: 아이패드에서 실행한 화폐전쟁을 공략 하나를 선택해 클리어.
- 기존에 사용자가 승인해 설치한 Appium / WebDriverAgent USB 조작 연결을 재사용한다. 화면 확인 후 에이전트가 개별 터치·드래그를 결정한다.
- Universal Control 설정은 현재 CUA에 아이패드 화면·입력을 직접 제공하지 않았다. QuickTime은 화면 보기 경로이며 터치 전달을 보증하지 않는다.
- 실기기 앱 목록에서 스타레일 4.6.1, WebDriverAgentRunner-Runner를 확인했다. 기존 Langrisser 연결 설정은 변경하지 않고 `.runtime/starrail-current/device.local.json`을 준비했다.
- 최초 재연결 실패 원인은 Xcode 결과 기록에서 확인한 개발용 설치 프로필 만료였다. 같은 개발팀과 앱 식별자로 `-allowProvisioningUpdates`를 사용해 갱신했으며 빌드·서명 성공을 확인했다. 새 기기 등록은 활성화하지 않았다.
- 갱신 후 두 번째 연결에서 프로필 만료 오류는 해결됐다. Xcode 로그는 설치된 개발자 앱 인증서가 아이패드에서 신뢰되지 않아 실행이 거부됐다고 명시한다. 사용자에게 아이패드의 설정 → 일반 → VPN 및 기기 관리에서 본인 개발자 앱 인증서를 신뢰하고 게임을 다시 열도록 요청했다. 사용자가 신뢰 완료를 알려 준 후 재연결이 성공했다.
- QuickTime에서 아이패드 화면 소스를 선택해 보기를 시도했으나 “작업을 완료할 수 없음” 경고가 나왔다. 이를 화면 제어 성공으로 기록하지 않는다.
- USB 조작 연결과 스타레일 화면을 실제로 확인했다. 현재 게임 진행 중이며 전체 클리어는 아직 미검증이다.
