## 실행 검증

출격 준비에서 N 산호 사격·에슈아룬의 성난 파도, F 시간의 판결·정면일격 이름/아이콘을 확인. 영상103초 F 중간 검은 인물 아이콘 대조하여 T2 정면일격으로 전사를 교정했다. 보물 획득은 실전에서 확인 후 남긴다. HP 차이만 있고 동일 위치·대상·생존 조건이 충족되면 기록하고 계속한다. 불일치 시 입력 확정을 보류하고 해당 영상 구간만 재검증한다. 패배·복구 불가시 재시작한다.
