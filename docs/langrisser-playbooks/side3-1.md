# side3-1 · アイリスの余燼

기록 상태: **2026-10-01 PERFECT 완료 — 업적2/2·보물1/1, 실제5턴 승리**. 영상 전사의 일반 공격/기술 오독2건을 수정했다.

한국어 실제 이름은 **아이리스의 잔불**. [최신 수동 실행표](iris-embers-grid-2026-10-01.md)를 우선한다. 이전 자료의 자동 실행/사용자 응답 대기/12초·20초 고정 대기 규칙은 사용하지 않는다.

## 목표

- 클리어 + 모든 업적 + 모든 상자/숨겨진 보물
- 업적 수: 2
- 보물: ゲート前 骨 (聖魔晶x100)
- 턴 제한: 10턴. 업적 제한은 5턴 내 승리.

## 행동 순서

[아이리스의 잔불 4턴 실행표](iris-embers-grid-2026-10-01.md)에 시작 격자, 최종 이동/대상, 연금 계승 선택, 각 적 턴 배치, 보물 획득과 마지막 처치를 기록했다. 전투 입력은 CUA 수동 조작만 사용한다. 미확인 기술명은 실제 한국어 설명과 아이콘을 대조하며, 불일치 시 확정하지 않고 공략 구간을 다시 확인한다.

## 현재 실제 상태

- 업적 **2/2**, 보물 **1/1**, 첫 클리어 보상 수령, 지도 **PERFECT**. 이미르4스택과5턴 내 승리를 모두 달성했다.
- 1회 재기동 후 보정 경로로5턴 승리. 완료 미션이므로 재출격하지 않는다.
- 맥 터치 대체 켬. 선택 해제 후 방향키 지도 이동, 짧은 drag 탭 입력 가능.
- [검증된 실전 기록](../../data/langrisser/verification/iris-embers-attempt-2026-10-01.md)에 전체 실제 행동을 저장했다.
