# 핏빛 날개 아래 / 血翼之下 — 수동 실행표

출처 https://www.bilibili.com/video/BV1wMJjzDEoC/ 梦战百科. 119초 영상의 배치부터 승리 정산까지 직접 검토. 실제 상세 제목·동굴/주황 수정/연못 맵 일치. 최초 목표 모든 적 격퇴, 2턴 이벤트에서 엘비스 탈출로 변경. 업적 실제: 전략화(승리 시 엘비스HP60% 이상), 쾌속질주(4턴 내). 보물 중간 비석. 초기0/2·0/1, 첫 보상 미수령.

좌표 원점=초기 엘비스(0,0), 동+x·남+y. 영상 약110px 격자. 초기 아군: 엘비스(0,0), 레이아(1,1), 타브리스(-1,1), 북서 흰 청소부A(-1,-1), 마법 청소부B(0,2), 기병 청소부C(2,2). A는 영상에서 창진(枪阵) 기술을 지닌 흰 부대이며 병종 아이콘은 녹색 화살처럼 보임. 실제 한국어 기술명/부대명은 전투 준비에서 확인.

기술 입력은 A의 창진1회만. 엘비스 스킬·공격 없음. 카메라가 움직이면 현재 배우·인접 부대로 격자 새 계산. 미리보기와 대기를 별도 확인. 영상1턴 적 턴에서 청소부C HP21%·일부 부대 희생, 엘비스100%가 관찰됨. 이 피해 차이만으로 재시작하지 않으며 엘비스 다음 이동·생존을 확인한다. 크리스탈 사용 금지.
