# main-3-1 · 再会と別れ

기록 상태: 준비 중

프레시아의 불굴을 준비해 파트리시아 단일기에 즉사하지 않게 한다. 왼쪽 위 열매에 보물.

## 목표

- 클리어 + 모든 업적 + 모든 상자/숨겨진 보물
- 업적 수: 2
- 보물: 左上 木の実 (聖魔晶x100)
- 턴 제한: 15

## 행동 순서

현재 자료에는 실행 가능한 전체 행동 순서가 없다. 위 전략 요약에서 임의로 클릭 계획을 생성하지 않는다.

### 2026-10-01 영상 대조 메모 (출격표 아님)

- [전 업적·보물 영상](https://www.youtube.com/watch?v=NXikhh47KjE): 제목의 `重逢與訣別`와 본 문서의 `再会と別れ`가 대응하며, 영상 시작 상세창에는 업적 `2/2`, 보물 `1/1`이 보인다. **실제 맥 게임의 한국어 미션명·시작 배치와는 아직 대조하지 못했다.**
- 영상 설명은 왼쪽 적부터 처치해 왼쪽 위 열매의 보물을 얻고, 이후 오른쪽 적을 정리한다고 한다. 이는 순서의 개요일 뿐 이동 칸·기술 표적의 근거가 아니다.
- 0:05 승리 조건은 아군 1명이 탈출 지점에 도달하거나 적 전멸. 0:10~0:35 아군이 좌측 적과 보물 쪽으로 이동·공격하며, 0:35에는 좌측 보물 근처에 3명 아군이 보인다. 각자의 확정 이동 칸·기술은 미확인.
- 0:40~1:05 오른쪽 적과 전투하고 0:50 적 턴을 확인했다. 1:10~1:25 왼쪽 아군에게 보호·회복 효과가 나타난다. 1:30 이후 오른쪽 최종 적에게 공격해 1:40에 양쪽 전투 HP가 0으로 보인다. 종료 화면의 실제 성공 여부·턴 수는 미확인.
- 영상의 좌측·우측 전투 장면을 5초 단위로 훑었지만, 이 속도로는 캐릭터별 흰 이동 경로, 기술 이름·표적, 대기, 턴 경계를 빠짐없이 확정할 수 없다. 출격 전 구간별 프레임 전후를 다시 확인해 [칸 좌표 실행 규칙](../LANGRISSER-GRID-EXECUTION.md)의 전체 확인표를 채운다.

## 미리 정한 예외 대응

- **잠깐의 화면 전환·인식 흔들림**: 카메라와 캐릭터 위치가 안정된 새 화면을 확인한 뒤 진행한다. 임의의 고정 대기 시간은 두지 않는다.
- **기록된 예외 결과와 일치**: 해당 분기를 Codex가 수동 입력한다. 피해량 숫자가 달라도 다음 행동에 필요한 조건이 일치하면 계속 진행한다.
- **대응 조건 없음·여러 분기 동시 일치·재시도 한도 소진**: 해당 입력을 보류하고 현재 화면·직전 단계·기대 결과를 저장한다. 공략 영상의 해당 구간과 현재 화면을 재검증해 기록을 수정하고, 필요하면 직접 재시작한다.
- **입력 후 결과 불명**: 같은 클릭을 반복하지 않는다. 결과 화면을 다시 관찰하고 공략의 해당 구간과 대조한다.

## 실행 준비에 남은 항목

- 단계별 행동 미작성
- 게임 화면을 누르는 실행 단계 미매핑
- 행동 순서 검토 미완료
- 한국어 화면·좌표 매핑 미완료
