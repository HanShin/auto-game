# 1-5 예측할 수 없는 여행 · 캐릭터·칸 번호 기록

2026-09-27 맥 실전 검증 완료: **클리어, 업적 2/2, 보물 1/1, PERFECT**. 별도 프로그램 없이 Codex가 CUA로 직접 조작했다. 아래는 이번 성공한 실행 경로이며 영상에서 확인한 단계와 실전 관찰을 구분한다.

## 고정 번호와 좌표

| 번호 | 캐릭터 | 전투 시작 칸 |
|---|---|---|
| ① | 롤랑 | C11-R11 |
| ② | 프레시아 | C11-R10 |
| ③ | 네미아 | C10-R11 |

롤랑의 전투 시작 칸을 C11-R11로 고정한다. C는 오른쪽으로, R은 아래쪽으로 증가한다. 게임 내 좌표가 아니라 기록용 기준이다. 카메라 이동으로 좌표를 바꾸지 않는다. 전체 맵 경계는 미확인이다.

## 완료 검증

- 업적 **신중한 행동**: 안드리올의 체력이 60% 미만인 상태로 승리. 달성 도장 확인.
- 업적 **적을 피하는 칼끝**: 프레시아가 피해를 받지 않음. 달성 도장 확인.
- 보물: C15-R14 꽃 칸. 보물 발견 대화와 150개 보상 확인.
- 첫 클리어 보상 수령 완료. 미션 상세에서 보물 **1/1**, 업적 **2/2**, 뒤쪽 목록 **PERFECT** 확인.

## 화면 이동과 확인 절차

1. 캐릭터 초상화와 이름, 고정된 출발 칸을 먼저 대조한다.
2. 목적지를 선택한 뒤 경로 미리보기의 행·열을 세고, 일치할 때 대기/기술로 확정한다.
3. 목적지가 화면 밖이라면 현재 이동 범위의 가시 칸을 클릭해 미리보기를 옮기면 카메라가 따라갈 수 있다. 확정 전 같은 이동의 목적지를 최종 칸으로 다시 지정한다. 중간 칸에서 대기하지 않는다.
4. T2 프레시아는 C09-R11에서 북쪽 정확히 5칸이다. 이번에는 단계적으로 미리보기를 옮겨 최종 5칸 경로를 확인한 뒤 확정했다.
5. 일반 빈 지도 드래그·스크롤은 CUA에서 화면 이동으로 처리되지 않았다. T3 화면 밖 프레시아를 선택할 때 사용자가 지도를 북쪽으로 한 번 옮겨 주었다. 따라서 무도움 조작까지 검증된 것은 아니다. 원인은 미확인이다.
6. 시침은 추가 이동이 아니라 후속 기술 선택이다. 재현되지 않는 상태나 미확인 행동은 추정해 진행하지 않는다.

## 이전 실패와 정정

- T2 프레시아를 C09-R09(위 2칸) 또는 C07-R09(왼쪽 2칸·위 2칸)에 둔 시도는 사망했다. 올바른 칸은 C09-R06이다.
- T1 프레시아를 C09-R10에 둔 시도는 첫 적 턴에 실패했다.
- 초기 영상 검토의 ‘보물 장면 없음’, ‘2–4턴 미확인’ 판정은 이번 상세 분석 및 실전 결과로 갱신했다. 영상 2:05–2:07에 보물 발견·보상이 실제로 있다.
- 이번 실전 T1 시침 후에는 대기를 사용했다. 영상 T2의 분홍 시계 쿨타임과 실전 표시가 달랐으므로 모든 버프/쿨타임이 영상과 완전히 같았다고 주장하지 않는다. 위 실제 경로로 전체 목표가 달성됐다는 점은 결과 화면으로 검증했다.
