## 실제 실행 기록

PC 1회 출격, 3턴 승리. 실제 PERFECT·업적2/2·보물1/1·첫 보상 수령함 확인. 크리스탈 사용0.

- 행1~9 확정 완료. 롤랑→군 영웅2941/병4920, 네미아로 군 격퇴, 산호 지형 설치와 회복2093/2007 확인. 무지개 페가수스 두 부대의 분뢰로 첫 흑천마 격퇴(첫 공격 후 영웅139/병0). 에쉬엔의 바람 칼날로 타브리스 격퇴: 처치 업적 1번째. 추가 대기 회복3799/2788.
- 프레시아 N(2,1)에서 관통→안드리올 확정. 고유 호위로 석궁 N(3,0)이 피해를 받고 안드리올은 생존하는 공략 결과 일치. 추가 시간 당기기를 자기 대상으로 확정, 회복3936/2958 후 적 행동으로 자동 전환.
- 실제 한국어 이름: 네미아, 무지개 페가수스, 타브리스. 기술: 롤랑 주형/눈부신 불꽃/징벌; 네미아 제압 사격/산호 사격/장갑 파괴, 고유 고고한 섬의 파도; 천마 분뢰; 에쉬엔 바람 칼날/긴 낮의 무지개/세브릭의 수호; 프레시아 시공의 여행자/시간의 판결/관통, 고유 추가 시간 당기기/시간 정지. 이후 변환 기술은 실제 메뉴에서 별도 확인한다.
- T1 적 행동에서 네미아 퇴각, 북쪽 석궁 한 부대와 마수 한 부대도 먼저 격퇴되어 행11 생략. 적의 자동 행동 상세 원인은 미확인으로 남긴다. 에쉬엔 위치와 두 번째 처치 대상, 롤랑 위치는 다음 필수 조건과 일치.
- 행12~16: 에쉬엔 S(1,-4) 긴 낮의 무지개 SELF→S(-1,-5) 일반 공격으로 흑천마 S(-1,-4) 격퇴(두 번째 처치)→추가 대기. 천마 PL S(1,-3), PR S(2,-2)에서 각각 대기. 행동 종료 뒤 자동 다음 유닛 선택으로 카메라가 북쪽 프레시아로 이동했다. PC의 좌클릭 드래그는 카메라 이동이 아니라 이동 미리보기였으므로 카메라 이동 수단으로 쓰지 않는다.
- 행17~20: 프레시아 N(0,0) 일반 공격→안드리올 N(1,0). 실제 공격 전후 안드리올 영웅1904/병0으로 보였고 영상의 부활2677/2872는 실제에서 검증되지 않았다. 프레시아 추가 시간 정지 SELF, 롤랑 N(-1,0) 주형 SELF→N(-2,-1) 징벌→안드리올 확정. 이후 북쪽 적들은 자동 반격에서 모두 격퇴됐다.
- T3 남쪽 PL 생존8650/병0, PR 퇴각. 흑천마가 영상 S(0,-3) 대신 실제 S(2,-3)에 도착했다. 영상242~243초 이동·표적을 재대조하고 에쉬엔 최종 칸 S(1,-4)은 유지, 실제 사거리2 안의 같은 병종 흑천마 S(2,-3) SE1을 바람 칼날 대상으로 확인하여 확정했다. 영웅10793/병9513 적 격퇴, 에쉬엔 세 번째 처치. 추가 파란 화살/눈 SELF 확정 후 회복3799/2788, 행동 종료. 살아남은 PL은 S(1,-3) 그대로 대기.
- 행24: 롤랑 N(-2,-1)→N(-5,-1) W3 흰 경로 끝이 용뼈 칸임을 확인. 동쪽 인접 N(-4,-1)을 보라 가로 범위 기술 방향으로 선택·확정. 실제 **보물 발견: 고대의 해골** 대화와 금빛 티켓2 아이템 획득 팝업을 확인했다. 초기 선택 직후 이동 범위가 덜 그려진 프레임은 확정 근거로 쓰지 않으며, 안정된 화면에서 이동3과 용뼈 칸의 파란 표시를 확인했다.
