# 희망 현혹: 검증된 턴별 격자 행동표

공략: [송기사TV — 이계의 울림 · 종전의 전조 2. 희망 현혹](https://www.youtube.com/watch?v=f0G1n9TZNLI) (1:39). 맥 게임의 미션 이름·승리 목표 `모든 적 격퇴`·레인폴즈 단독 배치·성채 지형을 영상과 대조했다. 화면 격자는 오른쪽 `+x`, 아래쪽 `+y`다. 각 행의 좌표는 **그 턴 시작 시 레인폴즈 칸을 (0,0)** 으로 다시 잡는다. 카메라 이동, 적의 밀치기/자리 변화 때문에 화면 픽셀이나 첫 턴 원점을 재사용하지 않는다.

| 턴 | 영상 시간 | 현재 적 배치(레인폴즈 기준) | 순서대로 입력할 행동 | 실제 맥 검증 |
| --- | --- | --- | --- | --- |
| 1 | 0:12–0:17 | 좌·우 첫 유령 | 시작칸에서 `(0,-2)` 이동 → 오른쪽 `(+1,0)` 유령 일반 공격. 공격 직후 추가 이동 없이 적 턴으로 넘어간다. | 오른쪽 유령 격퇴 확인 |
| 2 | 0:23–0:34 | `(-2,-1)`, `(-1,0)`, `(0,-1)` | **주황색 기술** 선택 → 바로 위 `(0,-1)` 유령 지정 → 공격 확정. 이동하지 않는다. | 위 유령 생존하나 약 23%로 감소 |
| 3 | 0:44–0:50 | `(-1,-1)`, `(-1,-2)`, `(0,-3)` | **붉은 소용돌이 광역 기술** 선택 → 빈칸 `(0,-2)`를 중심으로 지정. 세 유령이 모두 붉게 강조되는지 확인 → 확정. | 최상단 유령 격퇴, 두 유령 잔존 |
| 4 | 1:01–1:07 | `(-1,-1)`, `(-1,+1)` | 왼쪽 `(-1,0)` 빈칸으로 이동(두 유령 사이) → 바로 위 유령 일반 공격. | 위 유령 격퇴 |
| 5 | 1:11–1:18 | 마지막 유령 `(-1,+1)` | 아래 `(0,+1)` 빈칸으로 이동 → 왼쪽 `(-1,0)` 유령 일반 공격. | 마지막 유령 격퇴, 5턴 승리 |

3턴 광역 기술 직후와 적 턴에 레인폴즈 위치가 변하므로 매 턴 실제 상대 좌표로 재고정한다. 영상과 다른 피해 수치는 있을 수 있지만, 적 수·위치·생존 여부가 위 표와 다르면 다음 입력을 멈추고 공략 프레임으로 다시 확인한다. 첫 시도는 턴 표기 오독으로 2턴에 광역기를 일찍 써 흐름이 어긋났고, 재출격에서 위 순서로 검증했다. 크리스탈 사용 없음.

실제 결과: `고성의 지름길`(6턴 이내)과 `여유만만`(레인폴즈 생명력 30% 이상) 달성 팝업을 각각 확인했다. 보물 상자 카운터는 `-/-`. 전투 정산 후 상세 카운터는 별도 검증 기록에 남긴다.
