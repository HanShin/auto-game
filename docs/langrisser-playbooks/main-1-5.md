# main-1-5 · 예측할 수 없는 여행

2026-09-27 맥 실전에서 **클리어·업적 2/2·보물 1/1(PERFECT)**을 확인하고 첫 클리어 보상을 수령했다.

[캐릭터·칸 번호표와 검증된 4턴 행동](main-1-5-coordinate-ledger.md)을 실행 기준으로 사용한다. 영상 시점, 이동 칸, 기술·대상, 실제 결과를 기록했다. 프로그램 자동 플레이는 사용하지 않았다.

승리 조건은 4턴간 버티기다. 업적은 안드리올의 체력 60% 미만으로 승리하기와 프레시아가 피해를 받지 않기다. 숨은 보물은 C15-R14 꽃 칸이다.

T3에는 화면 밖 프레시아를 선택하기 위해 사용자가 지도만 북쪽으로 옮겼다. 일반 지도 드래그의 도구 입력 문제는 해결되지 않았다. 나머지 전투 행동은 Codex가 한 동작씩 직접 수행했다.
