# 아이리스의 잔불 — 영상 전 턴 수동 실행표

상태: **2026-10-01 PERFECT 완료 — 업적2/2·보물1/1**. 영상 원본4턴을 전사하고 기술 누락2건(T1-4/T3-4)을 수정했다. 실제 보정 경로는5턴 승리. [검증된 실제 행동 기록](../../data/langrisser/verification/iris-embers-attempt-2026-10-01.md)에 원본과 보정을 분리했다. 완료 미션은 재출격하지 않는다.

## 같은 미션 확인

## 실전 규칙

- 시작 배치와 한국어 기술 설명/아이콘을 확인한 뒤 첫 입력. 화면 클릭을 실행기에 맡기지 않는다.
- HP만 다르면 위치·대상·생존·다음 기술 조건을 확인하고 계속한다. 적 잔존/재행동/카메라 차이는 해당 구간 재검증. 복구 불가 또는 패배는 재출격.
- 크리스탈 사용 금지. 마지막 실제 상세창의 업적 2/2·보물 1/1·PERFECT 확인 전에는 완료라고 적지 않는다.
- AGENTS.md와 칸 좌표 실행 규칙이 이 문서보다 우선한다. 불일치로 사용자 응답을 기다리지 않는다.

한국어 준비 화면 확인: 셀리카 초기 스킬은 `윈드 커터`(단일 2칸), `빙룡의 숨결`(직선 범위), `등가교환`(저울). 이 영상은 빙룡의 숨결을 사용하지 않는다. 0:22 번개 계승, 1:12 등가교환, 1:47 幻愈术 시전 배너를 추가 대조해 처음 전사의 아이콘 오독을 출격 준비 중 수정했다.

## 2026-10-01 출격 관찰

- 배치 화면에서 셀리카 (7,0)와 용뼈 (4,-2)를 대조하고 공격 버튼으로 시작. 고정 아군 2명, 적 6부대의 전체 시작 배치가 영상과 일치했다. 턴 제한은 10턴이다.
- 전투 시작 자동 카메라가 이미르 중심으로 계속 이동했다. 첫 셀리카 선택 시도는 카메라 이동 때문에 빈칸 선택이 되었다. 전투 행동/이동/공격은 확정하지 않았다.
- 카메라 안정 후 셀리카가 화면 밖. CUA 긴 drag는 지도 이동 대신 끝 지점의 탭으로 전달됐고, 스크롤/방향키/Tab에도 지도 또는 아군 선택 반응이 없었다. 미니맵은 전장 정보 화면이며 아군을 눌러도 카메라 선택이 되지 않았다.
- 맥 앱 메뉴 → 설정 → 터치 대체의 실제 상태는 `끔`. 설명은 `드래그 마우스 포인터에서 드래그하려면 스크롤하십시오`, `쓸어넘기기 화면 중앙에서 쓸어넘기려면 화살표 키를 누르십시오`다.
- 설정을 켜기 위한 확인 요청 중. 설정 변경 전까지 현재 1/10턴, 두 아군 모두 미행동. 크리스탈 사용 없음.

## 터치 대체 변경 후 입력 복구

- 사용자가 `켰어`라고 알려준 뒤 실제 `켬=1`을 확인했다. 방향키 Left가 지도 쓸어넘기기로 전달돼 셀리카가 보였다.
- 변경 직후 좌표 click/drag가 `windowNotFoundAtPosition`으로 실패했다. AX 메뉴 입력/방향키/스크린샷은 됐다. 끔으로 잠시 비교해도 실패하여 켬으로 복원했다.
- CUA 연결 갱신, 커널 초기화, 전체 화면과 창 복원으로도 좌표 입력이 복구되지 않았다.
- 앱 정상 종료 후 재실행하고 실제 실행 중인 Wrapper 앱 경로로 연결했다. 시작 공지의 X를 짧은 drag로 눌러 정상 닫히는 것을 확인했고 게임 시작도 전달됐다. 실제 관찰상 앱 재실행 뒤 좌표 입력이 복구됐다. 설정 자체가 클릭 실패 원인이라고 단정하지 않는다.
- 마지막 설정은 터치 대체 켬이며, 전투 자동 실행 프로그램은 사용하지 않았다.

## 첫 실전 재검증과 수정

- 선택된 아군 상태에서는 방향키 지도 이동이 반응하지 않았다. 이동 불가능한 빈칸을 눌러 선택을 해제한 뒤 Left를 누르자 지도 이동이 됐다.
- 첫 시도 T1 셀리카 이동·윈드 커터·번개 계승은 기록과 일치했고, 용뼈 보물 100개 획득 창도 확인했다.
- T1-4를 일반 공격으로 잘못 전사했다. 실제 영상 0:34 공격 미리보기는 **빨간 발/돌격 아이콘, 공격 1803**이고, 첫 실전 일반 공격은 아이콘 없이 공격 1502였다. 망령이 살아남아 T2 배치와 분노 중첩이 달라졌다. 단순 HP 편차로 취급하지 않고 이 행을 수정해 재시작한다.
- 영상 1:56의 T3 첫 궁수 공격은 아이콘 없는 공격 1502로 일반 공격임을 추가 확인했다. 기술 사용과 일반 공격을 혼동하지 않도록 확정 화면의 공격 아이콘도 검사한다.
- 첫 시도 전투 행동은 CUA 수동 입력으로만 진행했으며 크리스탈 사용 없음. 보물 획득은 확인했으나 전체 PERFECT는 아직 미검증이다.

## 재출격의 현재 상태와 보정

- 실제 기술 설명: 빨간 발 `힘의 외침`(1.3배 단일, 전투 전 버프 2개 제거 및 공격/지력 -20%), 주황 방패 `방패 공격`(1배 단일, 전투 전 기절), 금색 `성문의 가호`(주위 3칸 아군의 행동 종료 시 디버프 1개 제거; 제거 성공 시 자신 분노 획득).
- 두 번째 시도 셀리카 계승 메뉴는 첫 시도의 파란 창 모양과 달리 실제 번개 모양이었다. 이름/위치를 고정하지 말고 실제 아이콘을 다시 확인해야 한다. 재출격에서 번개 계승 확정 배너를 확인했다.
- 재출격 강화 후 이미르의 실제 이동력은 3, 공격 1803. 보물 (4,-2)은 현재 이동 범위 밖이다. 첫 시도와 이동 범위가 다른 이유는 아직 미확인이다. 반복해서 이동 불가 칸을 누르지 않는다.
- 현재 전투의 보정 계획: T1 망령 옆 (3,-1)에서 `힘의 외침`으로 동일 적 (4,-1)을 공격하고, T2 필수 사용 칸 (4,-1)로 복구. 보물은 T3의 기존 필수 이동 (4,-2)에서 확인한다. 적 턴 후 배치/생존을 검증하고 복구 불가능하면 재출격한다. 이 계획은 현재 화면의 이동 가능 칸과 기술 사거리 관찰에 따른 보정이며 영상의 원래 경로와 구분한다.
- T1 보정 공격으로 상단 망령 처치. T2 셀리카 (5,0)에서 이미르 회복, 초록 치유 계승; 이미르 (3,-1)→(4,-1), 방패 공격으로 하단 망령 처치. T3 두 아군 생존, 이미르 분노 6스택. 실제 적 배치는 궁수 (3,-2), (6,-1), (3,0)으로 원래 영상과 다르다.
- T3 보정: 셀리카의 동일 치유/등가교환 계승을 완료. 이미르가 원래 보물 칸 (4,-2)로 이동해 현재 인접 궁수 (3,-2)를 일반 공격하고, 재행동으로 (3,-1)에서 아래 궁수 (3,0)를 공격한다. 영상의 상단 궁수→재행동→하단 궁수라는 순서를 유지하며, 바뀐 궁수 좌표와 공격 방향을 별도 관찰 기록으로 남긴다. T4 실제 잔존 적 위치/HP를 확인 후 다음 입력을 결정한다.
- T3 보물 획득(100)을 다시 확인. 재행동 일반 공격을 실행했으나 하단 궁수가 생존했다. 영상 2:02 미리보기를 다시 확인한 결과 **T3-4도 힘의 외침**이었다. 원본 실행표의 두 번째 기술 누락을 수정했다. T4 마지막 공격은 영상 2:36의 아이콘 없는 일반 공격으로 확인했다.
