# side2-6 · 逆転の術

기록 상태: **사용자가 직접 클리어, 맥 지도에서 PERFECT 3/3 확인** (2026-09-28). 동일 미션의 [전체 업적 영상](https://www.youtube.com/watch?v=FMtrYz7sWSk)에서 제목·목표·맵·초기 배치를 대조했다. 아래의 1턴 수동 재검증은 Codex의 실패한 별도 시도이며, 사용자의 성공 경로를 전사한 기록은 아니다.

W1 황제 처치·아군 재배치→철혈 강화진·처치→빛무녀 인접 강화·처치. W2 철혈 수병 처치·페라키아와 무녀 강화→페라키아 병종교환·처치→무녀 황제 강화·해골 처치→황제 보병 처치. W3 집정관 끌기·비병 처치→황제 창병 처치·아군 재배치→철혈 강화·수병 처치→페라키아 교환·처치→무녀 워프·해골 처치.

## 목표

- 클리어 + 모든 업적 + 모든 상자/숨겨진 보물
- 업적 수: 3
- 보물: なし
- 턴 제한: 미상

## 행동 순서

전체 행동 순서는 아직 없다. 아래는 영상 약 0:25–0:43과 Codex의 실제 맥 입력에서 **확인된 1턴 전반**이다. 사용자의 실제 클리어 경로와 혼동하지 않는다. 좌표는 캐릭터 현재 칸을 원점으로 한 상대 칸이며, 화면 픽셀은 카메라가 움직일 때마다 새로 계산한다. 이후 전사에는 [흰 경로선·기술 대상 확인 규칙](../LANGRISSER-GRID-EXECUTION.md)을 적용한다.

| 순서 | 영상에서 확인한 행동 | 맥에서 확인한 결과 |
|---|---|---|
| 1 | 황제 E1 이동 후 **파란 검 `검혼` 기술**로 북쪽 보병 공격 | 기술 사용 시 보병 전멸. 일반 공격은 보병을 남기므로 잘못된 입력 |
| 2 | 황제 재배치 기술로 철혈 지휘관을 황제의 **서쪽 1칸**, 이어 빛무녀를 원위치에서 **북쪽 2칸** 재배치 | 두 아군 위치 확인. 서북쪽이라는 중간 분석은 영상 오독이었음 |
| 3 | 철혈 지휘관 N1 이동 → 오른쪽 강화 기술 → `대기` → 재행동 N3 이동 → 왼쪽 화염 공격 기술로 기병 공격 | 병사 전멸, 기병 영웅 HP **11873/15178**. 영상 약 0:40의 전투 연출에는 영웅·병사 HP **0**이 표시되고, 직후 맵에는 기병이 다시 100%로 표시됨. 회복/부활 기전은 미확인 |
| 4 | 빛무녀를 기병 북쪽 칸으로 이동 | Codex 시도에서는 선택한 칸으로 이동되지 않음. 흰 경로선의 경유·도착 칸을 전사하지 않고 상대 위치만 해석했으므로 클릭 위치 오류 가능성이 있다. 사제 이동·기술은 미입력 상태에서 중단 |

영상 약 0:42–0:43에는 빛무녀가 적 북쪽에서 오른쪽 기술로 대상을 고르는 장면이 있다. 이때 기병이 같은 개체인지 새 개체인지, 0 HP 뒤 다시 100%가 된 이유는 **미확인**이다. Codex의 당시 화면에서는 기병 영웅 HP가 11873이며, 빛무녀는 전송받은 원래 칸에 있고 기술을 사용하지 않았다. 이후 기술 대상과 세 웨이브의 턴별 절차는 미확인이다. 사용자가 직접 클리어했으므로 이 차이가 미션 자체의 클리어 불가를 뜻하지 않는다.

## 2026-09-28 완료 확인 및 다음 전사 기준

사용자가 영상을 보며 직접 클리어했다고 알렸다. 이어 맥 게임의 `반격법` 상세 창에서 첫 클리어 보상 수령 표시, 업적 카운터 **3/3**, 지도 노드 **PERFECT 3/3**을 직접 확인했다. 숨겨진 보물 표시는 `-/ -`이며 위키도 보물 없음으로 적는다. 따라서 이 미션은 클리어·업적은 완료로 기록한다.

Codex 시도의 빛무녀 이동 실패를 '영상과 게임의 이동 규칙 차이'로 단정하지 않는다. 다음 미션부터는 영상에서 흰 경로선이 실제로 지난 칸을 시작→경유→도착으로 세어 기록한다. 기술은 시전자 현재 칸을 기준으로 대상 유닛의 상대 칸과 정체를 함께 기록하고, 기술 미리보기에서 선택된 대상 이름을 대조한 후 확정한다. **반격법의 세 웨이브별 정확한 칸·대상은 아직 미전사**이며, 재플레이용 확정 경로로 제공하지 않는다.

## 미리 정한 예외 대응

- **잠깐의 화면 전환·인식 흔들림**: 새 화면을 정해진 시간 동안 재확인. 기본 입력 전 12초, 입력 후 20초. 같은 결과가 서로 다른 두 캡처에서 확인되면 계속 진행.
- **기록된 예외 결과와 일치**: 해당 분기를 자동 실행. 피해량 숫자가 달라도 다음 행동에 필요한 조건이 일치하면 계속 진행.
- **대응 조건 없음·여러 분기 동시 일치·재시도 한도 소진**: 입력 중단. 현재 화면·직전 단계·기대 결과를 저장하고 사용자에게 요청. 해당 행동의 공략 사이트를 한 번 열고 영상 시점도 표시.
- **입력 후 결과 불명**: 같은 클릭을 반복하지 않음. 사용자 응답 후에도 결과 화면 관찰부터 재개.
