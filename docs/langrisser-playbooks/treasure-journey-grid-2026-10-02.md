# 보물 찾기 여행 · 수동 칸 실행표

## 기준과 입력

아군은 검은 투구 단일 탐색자. E/W/N/S는 **매 행 시작 시 실제 아군 칸** 기준이다. 화살표로 경유 칸을 적는다. 숫자는 칸 수이며 E1→S3은 동쪽 한 칸, 남쪽 세 칸이다. 돌 골렘·버섯의 발/HP 칸 중심과 파란 칸 두 개로 격자를 재측정한다. 장식 바닥 타일은 실제 이동 격자보다 작으므로 사용하지 않는다.

금색 기술은 영상 大力推击. 표적은 기술 사용 직전 아군 기준이다. 기술 후 재행동이 생기면 별도 행으로 다음 이동을 한다. `奋力疾行` 효과와 스태미나 차감이 지연되어 보이는 구간이 있으므로 효과 배너만으로 추가 이동을 추정하지 않는다. **행동 확정 뒤 안정된 칸**을 다음 원점으로 삼는다. 이동 미리보기에서 스태미나 숫자는 아직 차감 전일 수 있다.

영상 UI의 절대 턴 번호는 미확인. 단일 아군의 기술 재행동과 대기 시 턴 전환을 아래 순서로 전사했다. 보물 표기점은 이동해 대기한 뒤 **제자리 대기 한 번 더** 해야 탐색된다. 구역 시작 시 턴/스태미나가 갱신되는지 실전 확인한다. 재행동에는 턴 종료를 임의로 추가하지 않는다.

제자리 대기는 아군 선택 상태의 **대기 글자 또는 깃발 버튼을 직접** 누른다. 자동 재선택 직후 아군을 다시 누르면 선택이 해제되어 이어 누른 대기가 적용되지 않을 수 있다. 재도전 1구역에서 자동 재선택의 깃발을 직접 누르자 즉시 2구역 전환했다. 확정 뒤 녹색점 소멸 또는 구역 전환까지 확인한다. 첫 실전에서 아군 재클릭으로 선택을 해제하고 이 확인을 생략해 2구역 첫 점을 탐색하지 않은 채 떠났고 재기동했다.
