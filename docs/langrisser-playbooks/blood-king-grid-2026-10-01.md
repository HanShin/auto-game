## 출격 확인

- 실제 목표: 모든 적 격퇴. 업적0/2·보물0/1.
- 암흑 강타: 3턴 내 클리어. 칼끝의 춤: 님프 생명80% 이상으로 승리.
- 이미르와 님프의 시작 칸, 보물 균열, 보스와 적4명의 시작 칸 일치.
- 실제 이미르HP51224/51224, 병사 죽음의 도끼병12390/12390. 영상 병사는巨型灵俑14500/14500으로 다르다. 피해 숫자는 동일성을 요구하지 않으며 생존·위치·다음 기술 가능 여부로 판단한다.
- 실제 님프HP24966/24966, 이동3·사거리2, 기술 없음. 파란HP의 NPC이며 영상에서 직접 행동하지 않는다.
- 기술 이름과 아이콘: 성문의 가호(금색, 자신), 악행의 벌(불꽃, 적1칸), 철완(주먹, 자신). 실제 준비 화면 한국어 설명과 영상 배너 대조 완료.
- 영상 전체 행동 확인 완료. 미리보기와 최종 확정 구분. 마지막 행/다음 턴 배치 기록 완료.
- 크리스탈 사용 금지. 전투는 CUA로 한 단계씩 직접 입력.

## 좌표

2026-10-02 실제 전투에서 일반 적 한국어 이름 `시체`, 병사 `죽음의 도끼병`을 읽었다. 보스는 실제 한국어 리오벡, 병사 안개의 유령. 보스는 검은 머리·청록 구체, 나머지4명은 흰머리 시체 외형으로 구분한다. 전투 진입 뒤 이미르 병사 최대HP도14500으로 바뀌었다.

## 복구

미리보기 한 칸 오차는 취소/올바른 칸 재선택 후 확정한다. 위치·대상·생존 조건이 맞으면 HP 차이는 기록하고 진행한다. 패배나 필수 조건의 복구 불능은 재시작한다. 불일치는 해당 영상 구간만 다시 보고 기록을 수정하며 사용자 응답을 기다리지 않는다.
