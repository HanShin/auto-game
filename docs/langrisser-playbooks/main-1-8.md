# main-1-8 · 魔物死すべし · 마물에겐 죽음뿐

기록 상태: 준비 중

일본 위키에 기록된 마동포 2단계 전투 순서를 미리 저장했다. 1단계 4턴, 증원 후 2단계 4턴이다. 공격 위치와 스킬 선택은 전장 화면 매핑 후에만 실행한다.

## 목표

- 클리어 + 모든 업적 + 모든 상자/숨겨진 보물
- 업적 수: 2
- 보물: なし
- 턴 제한: 15

## 미리 정한 예외 대응

- **잠깐의 화면 전환·인식 흔들림**: 새 화면을 정해진 시간 동안 재확인. 기본 입력 전 12초, 입력 후 20초. 같은 결과가 서로 다른 두 캡처에서 확인되면 계속 진행.
- **기록된 예외 결과와 일치**: 해당 분기를 자동 실행. 피해량 숫자가 달라도 다음 행동에 필요한 조건이 일치하면 계속 진행.
- **대응 조건 없음·여러 분기 동시 일치·재시도 한도 소진**: 입력 중단. 현재 화면·직전 단계·기대 결과를 저장하고 사용자에게 요청. 해당 행동의 공략 사이트를 한 번 열고 영상 시점도 표시.
- **입력 후 결과 불명**: 같은 클릭을 반복하지 않음. 사용자 응답 후에도 결과 화면 관찰부터 재개.
- **1단계 완료로 적이 증원되고 턴 4 표식이 다시 나타남**: 왼쪽·오른쪽 끝과 중앙 두 포탑을 다시 식별하고 2단계 T4 기록 적용. 같은 턴 표시만으로 기존 단계 완료로 오인하지 않음.
- **기록된 퍼센트 HP 또는 대상 위치와 일치하는 적을 찾지 못함**: 대상을 추측하지 않고 화면을 재확인. 계속 불일치하면 질문하고 해당 위키 공략을 연다.

## 실행 준비에 남은 항목

- 일본 위키 순서는 기록했으나 한국어 기술 버튼·범위·대상 좌표는 전장 화면에서 검증 전.
- 일반 공격·충전 후 대기·적 턴 종료 UI 동작을 자동 계획으로 매핑 전.
- 실제 배치된 두 단계의 적 HP·포탑 재배치와 2개 업적 조건을 확인 전.
- 이전 검증에서 T3 하피는 HP 66% 상태에서 일반 공격 6216 피해를 받고 생존했다. 위키의 처치 결과와 불일치하므로 원인 확인 전까지 해당 순서는 검증되지 않음.
- 목표 main-1-8의 정확한 한국어 영상은 확인되지 않았다. 동명 4-1 영상은 다른 미션으로 제외.
- 게임 화면을 누르는 실행 단계 미매핑
- 한국어 화면·좌표 매핑 미완료
