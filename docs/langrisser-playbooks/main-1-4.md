# main-1-4 · 섬의 손님

기록 상태: 준비 중

이전 영상 대조와 실전 관찰을 사전 행동표로 정리했다. 1턴 시간 기술 오류를 수정했다. 9턴 비치명타 후속 행동과 자동 화면 매핑은 아직 준비 중이다.

## 목표

- 클리어 + 모든 업적 + 모든 상자/숨겨진 보물
- 업적 수: 2
- 보물: 箱(聖魔券x2)
- 턴 제한: 15

## 행동 순서

롤랑 최초 시작 칸=(0,0), 오른쪽 +x, 아래 +y. 상대 칸 기록이며 카메라에 따른 픽셀 좌표가 아니다.

|---|---|---|---|
| 1 · t1-1 | 1 · 롤랑 | (0,2)로 이동 → 주형 → 징벌로 (-1,3) 적 공격 | 초기 왼쪽 적 처치, 주형·징벌 순서를 바꾸지 않음. |

| 3 · t1-3 | 1 · 네미아 | (1,3) 이동 → 녹색 공격 기술로 (0,4) 적 공격 | 초기 두 적 처치. 생존하면 첫 턴 업적이 위태로워 기록 없는 후속 입력 중단. |

## 미리 정한 예외 대응

- **잠깐의 화면 전환·인식 흔들림**: 새 화면을 정해진 시간 동안 재확인. 기본 입력 전 12초, 입력 후 20초. 같은 결과가 서로 다른 두 캡처에서 확인되면 계속 진행.
- **기록된 예외 결과와 일치**: 해당 분기를 자동 실행. 피해량 숫자가 달라도 다음 행동에 필요한 조건이 일치하면 계속 진행.
- **대응 조건 없음·여러 분기 동시 일치·재시도 한도 소진**: 입력 중단. 현재 화면·직전 단계·기대 결과를 저장하고 사용자에게 요청. 해당 행동의 공략 사이트를 한 번 열고 영상 시점도 표시.
- **입력 후 결과 불명**: 같은 클릭을 반복하지 않음. 사용자 응답 후에도 결과 화면 관찰부터 재개.
- **1턴 프레시아의 분홍 시간 기술 선택 화면**: 기록은 대기다. 기술을 추가 사용하지 않고 확인된 대기 버튼으로 종료.
- **3턴 네미아 공격으로 적이 영상보다 일찍 처치됨**: 다음 롤랑의 별도 대상을 확인하고 정해진 순서 유지.
- **4턴 프레시아 공격 후 적 생존**: 영상의 이후 적 턴 진행 뒤 두 적 제거·프레시아 생존 조건을 확인. 조건 불충족 시 질문.
- **9턴 바깥 적 미처치 또는 체력 판독 불명**: 지정한 관찰 예산 내 다시 확인. 처치가 확정되지 않으면 출구 이동 금지, 현재 화면과 미처치 정보를 묶어 사용자에게 요청.

## 실행 준비에 남은 항목

- 녹색 공격·금색 범위 기술의 정확한 한국어 이름과 전체 UI 입력 좌표 미매핑.
- 9턴 비치명타에 대응하는 구체적인 공격 순서 미작성.
- 입력 전후 칸·적 생존 판정, 카메라 이동 및 HP OCR 오인식 대응 매핑 필요.
- 원본과 같은 순서의 완주 재검증 및 업적 2/2·상자 1/1 사후 확인 필요.
- 게임 화면을 누르는 실행 단계 미매핑
- 행동 순서 검토 미완료
- 한국어 화면·좌표 매핑 미완료
