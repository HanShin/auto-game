## 좌표와 기술

상아 부대 최초 칸=(0,0), 동+x, 남+y. 중앙 별=(3,1), 포털=(6,0). 통화=(4,4),(8,4),(8,-4),(4,-4). 주력=P, 첫 소환 보병=B, 두 번째 창병=L.

P 중간 빨간 원형 칼 기술=사거리5 단일 공격, 한국어 이름 미확인(입력 전 실제 정보 확인). P 아래 교차칼=인접 단일 공격, 한국어 이름 미확인. P 위 파란 번개는 사용하지 않는다. B 주황 발 기술과 L 금색 강화 기술의 한국어 이름도 실제 정보 확인 전 미확인으로 둔다. 용병 소환은 통화 두 개 획득 후 대기에 이어 나오는 자동 선택 단계로, 독립 공격 기술이 아니다.

한 동작씩 수동 입력하고 현재 행동자와 고정 지형으로 화면 격자를 다시 맞춘다. 이동 뒤 행동 메뉴/흰 최종 경로, 공격 전 대상 이름·병종·아이콘을 검증한다. 모든 아군 행동 종료 후 적 턴이 자동으로 시작한다. 소환 칸과 병종 선택은 별도 단계로 실행한다.

## 연결 중단과 재개

전사 완료 뒤 상세의 업적 창 닫기 입력은 기존 아이패드 주소 연결 시간 초과로 전송되지 않았다. 기기 연결 정보를 새로 읽어 바뀐 주소로 동일한 제어 세션을 복구했으나, 아이패드가 잠겨 게임 전면 표시가 거부되었다. 사용자에게 직접 잠금 해제·게임 열기를 요청했다. 아직 이 미션에 출격하지 않았고 전투 확정 입력·자원 소비는0이다. 잠금 해제 뒤 현재 상세/출격 화면을 먼저 확인하고 위 표를 재사용한다.
