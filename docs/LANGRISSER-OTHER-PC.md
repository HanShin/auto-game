# 다른 PC에서 랑그릿사 이어서 진행하기

이 저장소는 공략·턴별 실행표·실제 완료 기록과 수동 좌표 계산 도구를 공유한다. 전투 입력은 현재 PC에 연결된 Computer Use로 한 동작씩 수행한다. 독립 자동 전투 프로그램을 설치해 실행하는 구성은 아니다.

## 가져오기

```sh
git clone https://github.com/HanShin/auto-game.git
cd auto-game
node scripts/portable-check.mjs
```

Git은 소스 동기화에, Node.js 20.19 이상은 선택적인 자료 검사·좌표 계산·테스트에 사용한다. Markdown 공략을 읽고 CUA로 진행할 때는 `npm install`이 필요 없다. 이전 Mac/iPad 도구의 Appium·Xcode·Swift는 Windows 수동 진행에 필요 없다.

이전에 복제했다면 게임 진행 전에 `git pull --ff-only`로 갱신한다. 로컬에서 작성한 기록이 있다면 먼저 커밋하고 동기화한다. 현재 작업 폴더를 Codex 프로젝트로 열어 `AGENTS.md`와 최신 기록을 함께 읽도록 한다.

## 게임과 입력 연결

1. 해당 PC에 공식 랑그릿사 클라이언트를 설치한다. 게임 설치·로그인은 소스 복제로 이전되지 않는다. 동일 계정에서 이어서 하려면 그 계정으로 직접 로그인한다.
2. Windows에서는 게임을 **일반 권한**으로 실행한다. 이 PC에서는 관리자 런처가 입력을 막았고, 파일 탐색기에서 실제 `client/Langrisser.exe`를 직접 열어 일반 권한 실행·클릭을 확인했다. 새 PC에서는 실제 설치 경로를 확인한다. 기존 `C:\Langrisser` 경로나 로컬 바로가기를 그대로 쓰지 않는다.
3. 현재 PC에서 native 앱 화면 캡처와 입력을 제공하는 Computer Use 연결을 준비한다. 도구가 브라우저만 제어할 수 있다면 PC 게임 입력은 불가능하므로 먼저 native 앱 제어 가능 여부를 확인한다. 이 저장소가 제어 도구나 그 권한을 설치하지 않는다.
4. 새 화면 캡처에서 게임 창 제목과 화면을 확인하고, 되돌릴 수 있는 메뉴 열기·닫기로 클릭을 검증한다. 지도 드래그는 실제 카메라가 이동했는지 따로 확인한다. 로그인/UAC/잠금 해제 등 사용자 조작이 필요한 화면은 직접 처리한다.
5. 게임이 보이는 로그인된 데스크톱에서 진행한다. 잠금 화면이나 화면 연결 상태가 달라지면 전투 입력을 중지하고 새 캡처로 확인한다. 화면 잠금 상태에서의 동작은 검증하지 않았다.

이 PC의 클릭은 정상이나 전투 지도 CUA 드래그가 끝점 클릭처럼 처리된 사례가 있다. 드래그 성공을 가정하지 않는다. 필요하면 다른 유닛의 **미확정 이동 미리보기**로 카메라를 옮긴 뒤 원점 복원과 배치를 확인했다. 추가 행동 중 사용할 수 없을 때는 사용자에게 전투 입력 없이 지도만 이동하도록 요청했다. [최신 실행표](langrisser-playbooks/sea1-storm-encounter-grid-2026-10-09.md)에 실제 사례가 있다.

## 진행 기록 인계

- [최신 상태 요약](../data/langrisser/current-session.json): 마지막 검증한 계정의 상태이며 라이브 동기화가 아니다.
- [최신 검증 로그](../data/langrisser/verification/pc-2026-10-08.md): 2026-10-09 완료까지 포함한다.
- 마지막 완료: 바다 섬의 장Ⅰ 02 **폭풍의 우연**, 3턴 승리·업적2/2·보물1/1·첫 보상 수령함. 사용자 요청에 따라 여기에서 멈췄다. 새 진행 요청 전에는 다음 미션을 출격하지 않는다.
- 평원Ⅰ·Ⅱ·Ⅲ은 모두 100%로 검증했고, 바다 섬의 장Ⅰ 01 심판의 탑도 업적2/2·보물1/1로 완료했다. 다른 PC 또는 계정의 실제 상세 카운터와 다르면 현재 게임 화면을 우선한다.

새 PC의 Codex에 다음처럼 요청할 수 있다.

> AGENTS.md, docs/LANGRISSER-OTHER-PC.md와 data/langrisser/current-session.json을 읽어줘. 현재 PC의 랑그릿사 캡처·메뉴 클릭·지도 드래그부터 검증하고, 실제 게임 상세 화면과 최신 검증 기록을 대조해 다음 미클리어 미션을 진행해줘. 출처를 확인한 턴별 실행표와 CUA 수동 입력만 사용하고, 크리스탈은 쓰지 마.

## 해상도와 경로

이전 화면의 픽셀 좌표·창 ID·스크린샷 ID는 새 PC에서 재사용하지 않는다. 매번 현재 화면에서 행동할 아군과 고정 지형 칸으로 격자를 다시 맞춘다. [칸 좌표 실행 규칙](LANGRISSER-GRID-EXECUTION.md)을 적용하며, 좌표 계산 모듈의 `visible`, 격자 간격, 오차 제한은 현재 화면에 맞게 전달한다. 모듈은 게임을 클릭하지 않는다.

문서·상태 요약의 경로는 저장소 상대 경로를 쓴다. `scripts/environment.mjs`도 소스 위치를 기준으로 프로젝트 경로를 계산한다. 과거 기록의 `.runtime/` 증거와 118MB의 과거 원본 PNG는 당시 로컬 보관 자료이며 저장소에 포함하지 않는다. 과거 문서의 해당 이미지 링크는 새 PC에서 열리지 않을 수 있다. 최신 폭풍의 우연 완료 증거 JPG는 함께 버전 관리한다.

`device.local.json`, `.env*`, `.runtime/`, `node_modules/`, `dist/`, 로컬 바로가기는 공유하지 않는다. 계정 비밀번호·인증 정보는 파일이나 채팅에 저장하지 않는다. 기존 Mac 전용 CLI·Langrisser Pilot 자료는 과거 구현 참고용이며 현재 전투 진행 지침을 대신하지 않는다.

## 확인 범위

```sh
node scripts/portable-check.mjs
node --test test/langrisser-grid-reference.test.mjs
```

자료 검사·좌표 계산은 운영체제별 native 도구 없이 실행된다. 실제 게임 클릭·전투·업적·상자 완료는 현재 Windows PC에서 검증했다. 다른 PC의 게임 연결과 입력은 그 PC에서 위 순서대로 확인해야 한다.
