## 전체 진행 가능 여부에 대한 결론

1. **공략 존재 여부:** 84개 스테이지에 전략 요약이 저장되어 있다. 34개는 현재 사실 정보만 있어서 전투 공략 후보에서 제외했다.
2. **정확한 행동 순서:** 원문에 턴 표기가 있는 미션도 25개이며, 일부는 증원 턴·기믹 설명만 있다. 순서가 완성된 것처럼 간주할 수 없다.
3. **프로그램 실행 준비:** 전체 118개 중 준비 완료 0개다. 캐릭터·기술명만으로는 화면 좌표와 타깃을 안정적으로 누를 수 없고, 스테이지별 UI 매핑이 필요하다.
4. **완주·업적·보물 검증:** 자동 클리어가 확인된 미션은 0개다. 문서의 업적 수/보물 정보는 목표의 개수·존재 여부를 말할 뿐, 게임에서 전부 획득했다는 증거가 아니다.
5. **캠페인 범위:** 현재 위키 목차는 외전 4장과 본편 8장까지 118개다. 본편 9~11장은 목록에 개별 페이지가 없다고 저장되어 있고, 한국 서버 전체 미션 목록 대조도 끝나지 않았다.

따라서 지금 확인 가능한 범위에서 “공략 없는 것 제외하고 전부 자동 진행 가능”하다고 답할 수 없다. 우선 전략 요약 후보 84개 중 사용자가 진행할 대상과 동일한 미션을 대조하고, 정확한 행동 순서가 있는 것부터 화면 매핑·단계 기록·목표 검증을 완료해야 한다. 자동으로 끝난 것으로 표시하지 않는다.
