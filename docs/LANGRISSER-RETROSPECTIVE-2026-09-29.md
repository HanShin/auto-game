## 속도를 높일 실행 방식

1. **출격 준비를 한 번에 끝낸다.** 실제 미션명·목표·맵·시작 배치와 영상이 같은지 확인하고, 이미 달성한 업적·상자 수를 기록한다. 필요한 경로의 시작부터 승리까지 턴·순서·배우·흰 이동 경로·기술·대상·설치 뒤 이동·턴 종료를 전사한다. 미확인 칸은 채우지 않는다. 이 단계가 가장 큰 재출격 감소 효과를 기대할 수 있다.
2. **긴 문장 대신 짧은 실행표 한 행씩 사용한다.** 예: `T10 폭탄맨 S1E1 → 폭탄 E1 → 재이동 N1W1 → 대기 → 다음 턴 위치 확인`. 두 좌표 기술과 재행동은 별도 행으로 나눈다. 미리보기 좌표와 확정 좌표를 분리하면 항해 표식 같은 누락을 줄인다.
3. **게임 화면만 매 동작 확인하고 영상은 불일치 때 해당 시점만 다시 연다.** CUA로 한 동작을 입력한 직후 현재 화면을 확인한다. 이동 미리보기·기술 대상·전투 미리보기처럼 되돌릴 수 없는 확정 직전에 집중하고, 이미 검증된 긴 연출을 반복해서 프레임별 비교하지 않는다. 클릭과 화면 확인을 같은 도구 호출로 묶어 왕복 시간을 줄인다.
4. **상대 칸을 현재 화면에 재투영한다.** 선택한 캐릭터와 고정 지형 두 점으로 화면 격자를 다시 맞춘다. 카메라가 이동했거나 유닛이 재행동·변신했으면 이전 픽셀 좌표를 버린다. 표적은 '가장 가까운 적'이라는 추측 대신 영상에서 확인한 이름·병종·주변 배치와 현재 미리보기를 일치시킨다.
5. **불일치는 중요도에 따라 처리한다.** 숫자 HP 차이만 나면 진행한다. 위치·대상·기술·적 생존이 달라지면 확정 전 취소하고 출처의 해당 구간을 재검증한다. 이미 한 칸 빗나갔어도 다음 행동에서 출처와 동일한 배치를 복구할 수 있으면 기록 후 계속한다(항해 표식 10→11턴 사례). 패배하거나 복구할 수 없는 핵심 조건이 틀리면 재시작한다. 크리스탈은 사용하지 않는다.
6. **완료 판정을 한 번에 마무리한다.** 승리 연출 뒤 해당 노드를 다시 열어 업적·보물 카운터를 확인하고 실행 기록에 남긴다. 업적·상자만 놓친 승리라면 미달 항목과 공략 링크를 적고 다음 미션으로 간다. 전투 패배는 같은 미션을 재도전한다. 완료 영상 탭은 닫는다.

게임의 x4 속도와 모션 OFF는 이미 사용하고 있다. 추가 속도 개선의 우선순위는 애니메이션 설정보다 **완전한 전사 → 적은 재시작 → 필요한 화면만 확인 → 탭 정리**다. 속도 단축률은 다음 몇 미션에서 출격 횟수와 재확인에 쓴 시간을 기록한 뒤 평가할 수 있다.

`data/langrisser/progress.json`은 2026-09-27의 본편1-4 진행 상태에 머물러 있고, 일부 초기 자동 실행 문서는 현재 수동 CUA 방식보다 오래된 계획을 설명한다. 다음 미션을 고를 때 이 파일만 기준으로 삼으면 이미 끝난 스테이지나 업적을 다시 시도할 수 있다. 현재 상태 판정은 **게임 상세 화면과 최신 `data/langrisser/verification/` 기록**을 우선한다. 오래된 출격 기록은 실패 원인과 변경 이력을 보존하되, 각 스테이지 문서 맨 위에 최신 검증 결과를 적는다.
