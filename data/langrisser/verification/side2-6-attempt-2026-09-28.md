# 반격법(side2-6) 수동 검증 · 2026-09-28

- 출처: https://www.youtube.com/watch?v=FMtrYz7sWSk , https://hisa-memo.com/lang-gate-2311/
- Codex 시도 당시 상태: 1턴에서 입력 중단, 승리·패배 결과 없음. 크리스탈 사용 없음. 이후 사용자가 영상을 보며 직접 같은 미션을 클리어했다.
- 첫 재시도에서 황제의 일반 공격을 기술 공격으로 잘못 읽어 보병이 생존했다. 다시 시작해 **파란 검 `검혼` 기술**로 첫 보병 처치를 확인했다.
- 황제 재배치 위치는 철혈 지휘관 `황제 서쪽 1칸`, 빛무녀 `원위치에서 북쪽 2칸`이 영상과 일치한다. 중간에 서북쪽이라고 본 것은 영상 오독이었다.
- 수정 후 재출격에서 철혈 지휘관의 강화·재행동·왼쪽 화염 기술까지 영상 순서대로 입력했다. 기병의 병사는 전멸했으나 영웅 HP **11873/15178**이 남았다. 영상 약 0:40 전투 화면에서는 기병 영웅·병사 HP **0**이 표시되지만 직후 맵에는 기병이 다시 100%로 보인다. 동일 개체의 회복/부활인지 다른 개체인지는 확인되지 않았다. 앞서 영상의 1525 HP는 전투 연출 중간 수치였다.
- 영상 약 0:41–0:42의 빛무녀는 기병 북쪽 칸으로 이동한다. Codex가 같은 상대 칸이라고 해석한 지점을 눌렀으나 이동되지 않았다. **영상의 흰 이동 경로선에서 경유 칸과 끝 칸을 세지 않았으므로 목적지 해석 오류 가능성이 있다.** 사제의 이동·기술은 입력하지 않고 턴 종료 전에 중단했다. 최초 일반 공격/기술 오독도 별개의 입력 오류였다. 피해량 차이의 원인은 여전히 미확인이다.
- 사용자는 영상을 직접 보며 `반격법`을 클리어했다고 보고했다. 이어 맥 게임의 `반격법` 상세창에서 **첫 클리어 보상 수령, 업적 3/3**, 지도에서 **PERFECT 3/3**을 Codex가 확인했다. 위키상 보물은 없음. 사용자 경로의 턴별 이동·기술 순서는 아직 기록되지 않았으므로 이 Codex 시도를 성공 경로로 재사용하지 않는다.
- 이후 전사 규칙: 영상의 흰 경로선을 시작→경유→도착 칸으로 기록. 기술 대상은 시전자 현재 칸과 상대 칸, 이름·진영·병종으로 식별. 실제 게임에서 기술 미리보기의 선택 대상까지 맞으면 확정한다. 불명확한 대상이나 다른 결과는 입력을 멈추고 공략을 다시 확인한다.
