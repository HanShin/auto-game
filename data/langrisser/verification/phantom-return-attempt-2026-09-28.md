# 환령의 귀로 · 2026-09-28 첫 출격 검증

> 최신 결과: [무변신 칸 좌표 기록](../../../docs/langrisser-playbooks/phantom-return-no-lobster-grid-2026-09-28.md)에 따라 3턴에 클리어했다. 지도 **CLEAR·업적 1/3**, 보물 표시 `-/-`. `랍스터로 변신하지 않음` 업적과 첫 클리어 보상 확인. 크리스탈 지출 0. 아래는 이전 실패 이력이다.

- 게임 진입 전: 업적 0/3, 상자 `-/-`, 첫 클리어 보상 미수령.
- 영상 출처: https://www.youtube.com/watch?v=1syF6bbOTqs (실제 맵·시작 유닛·업적 조건 일치).
- 첫 랍스터 처치/변신/재행동: 확인.
- 기사 공격: 파란 소용돌이 기술 누락. 게임에서 아군 랍스터 전사, 실패 알림 확인.
- 실패 후 크리스탈 100개 부활 제안: 취소. 완료 업적 없음.
- 이후 상태: 전투 지도의 실패 직후 화면. 진행 입력 중지. 공략 영상은 사용자에게 표시 중.
- 다음 시도: 영상 21~22초의 기술을 먼저 선택하고 기사 대상 확인. 나머지 경로는 영상에서 더 전사해야 함.

## 재출격 결과

- 사용자의 재출격 지시를 받고 같은 미션에 다시 출격. 1턴 내내 영상과 대조하며 수동 조작.
- 시작의 영→랍스터→기사→랍스터→랍스터→랍스터→보병→기사까지 변신·재행동 확인. 파란 소용돌이와 붉은 기술을 각 공격 전에 선택해 전투 미리보기를 확인함.
- 보병 공격은 영상과 같은 물/DEF 0% 대 숲/DEF 20%, 적 HP 13,467로 대조하여 성공. 서쪽 숲 보병 처치 후 보병 변신.
- 보병이 기사를 공격할 때 이동하지 않은 것이 영상과 다른 위치를 만든 것으로 추정. 기사로 변신 후 영상은 숲/DEF 20% 랍스터를 공격하지만, 실제 게임에서는 바로 위 물/DEF 0% 랍스터를 공격하는 다른 분기로 진행해 전사. **전투 실패**, 업적 완료 증거 없음.
- 두 번째 100 크리스탈 부활 제안도 취소. **크리스탈 사용 0**. 게임은 실패 결과 화면에 둠.
- 자세한 행동 순서와 미검증 지점: `docs/langrisser-playbooks/phantom-return-2026-09-28.md`.

## 세 번째 출격 결과

- 사용자 요청에 따라 같은 `환령의 귀로`를 재출격. 영상 제목·시작 배치·맵 일치 확인. 전투 입력은 CUA 수동 조작으로 수행.
- 첫 9번의 처치/변신/재행동은 성공. 이전 실패 지점인 보병→위쪽 기사와 기사→숲 랍스터를 수정해 통과.
- 10번째 공격으로 기사 변신까지 했으나 영상 76~78초의 이동 칸·기사 대상과 정확히 일치했는지 미검증. 다음 영상 대상인 랍스터 대신 게임에서는 보병이 보였다.
- 보병 공격은 불리한 상성으로 미리보기에서 취소. 서남쪽 기사에게 동종 공격을 했으나 양쪽 5,352 피해 후 아군 사망으로 GAME OVER. **클리어·업적·상자 미확인.**
- 크리스탈 사용 0. 게임은 `터치하여 계속 진행` 화면. 사용자의 최근 지침은 업적 미달 시 계속 진행하는 것이지만, 이번에는 실제 패배로 전투 진행 불가.
- 재출격은 영상 72~79초를 프레임별로 전사하고 9·10번째 대상과 도착 칸을 특정한 뒤 진행해야 함.
